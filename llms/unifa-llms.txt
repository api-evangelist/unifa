# Unifa Inc. (ユニファ株式会社)

> Unifa Inc. is a Tokyo-based childcare-technology company founded in May 2013 that develops and
> operates Lookmee (ルクミー), a comprehensive ICT, IoT and AI service for Japanese nursery schools,
> kindergartens, certified children's centers, municipality-run facilities and after-school clubs.
> Unifa publishes NO public API. There is no developer portal, no API reference, no OpenAPI or
> AsyncAPI specification, no SDK, no CLI, no webhook catalog and no MCP server. An agent cannot
> integrate with Lookmee programmatically from public materials.

## Integration surface

- The Lookmee product API host `https://api.lookme-e.com` resolves and is live, but answers
  `{"message":"Forbidden"}` (HTTP 403, AWS API Gateway) to every anonymous request on every path
  probed. It is the product's own backend, not a developer surface.
- Every named `/.well-known/` path — security.txt, openid-configuration, oauth-authorization-server,

- No first-party SDK exists on npm, PyPI, RubyGems, Maven Central, NuGet, crates.io or pkg.go.dev.
